How to read this

The replay runs the same decision engine as the live proxy over each recorded request. Token counts are the measured ones; on a model switch, cached tokens the new model hadn't seen are re-priced as cache writes. Output length is held constant across models, and savings from lower effort aren't counted, so the estimate errs low on cost savings. The replay can't measure answer quality; validate a preset in shadow mode, then live, before relying on it.
